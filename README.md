## Quantitative Finance Models

| Model | What it does |
|---|---|
| [Yield Curve Monitor](https://github.com/sidneyppratt-svg/yield-curve-monitor) | Tracks Treasury yield curve spreads, detects inversions, and backtests a rates strategy |
| [Multi-Asset Regime Detector](https://github.com/sidneyppratt-svg/quant-regime-detector) | Detects RISK-ON / RISK-OFF market states across equities, bonds, credit and gold using a Gaussian Mixture Model |
| [Credit Spread Monitor](https://github.com/sidneyppratt-svg/credit-spread-monitor) | Monitors credit market stress using HYG vs LQD spreads across 16 years of data |
| [Mortgage Market Monitor](https://github.com/sidneyppratt-svg/mortgage-market-monitor) | Estimates mortgage rate conditions from Treasury yields and MBS performance to signal refinancing activity |

All four models run live on real market data at [sidneyppratt.com](https://sidneyppratt.com).
